# Retiro de la app Qt — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Borrar la app de escritorio (PySide6) y todo lo que solo la sirve, sin romper el núcleo, la web ni sus pruebas.

**Architecture:** Borrado por grupos (código, pruebas, dependencias, diseño, documentación) con una etiqueta `qt-final` como respaldo. Lo único del núcleo que queda en `an/nucleo/` es `xlsx.py`.

**Tech Stack:** Python 3.13, pytest, GitHub Actions, FigCraft (MCP `figcraft-app`).

**Spec:** `docs/superpowers/specs/2026-10-26-retiro-qt-design.md`

## Global Constraints

- Respaldo antes de borrar: etiqueta `qt-final` en el commit vigente, subida a `origin`.
- Nada fuera de `.venv` importa `PySide6`.
- Se queda: `an/nucleo/xlsx.py`, el núcleo puro de `an/turnos` y `an/radiologia`, la `BD` con SQLite, `ejemplos/`.
- Si una prueba de lógica pura importa Qt de paso, se corrige el import, no la prueba.
- Rama `retiro-qt`; al terminar: push → PR a `main` → fusionar con CI verde.
