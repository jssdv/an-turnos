> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Los pasos usan casillas (`- [ ]`).

> **Retomar en otra sesión:** busca el primer `- [ ]` sin marcar. Marca cada paso y commitea este archivo junto con el trabajo. Al cerrar, marca la Fase 4 en `docs/PLAN_WEB.md` (§0 y §6) solo si se cumple la aceptación.

**Goal:** Ver el cuadro de Esterilización en el navegador con el aspecto de `docs/diseno/esterilizacion_cuadro.png`, ingresar, cambiar contraseña y lanzar «Generar» con progreso y Cancelar.

**Architecture:** `web/` (Vite + React 19 + TS). Estado de sesión en un contexto; datos con `fetch` propio (`web/src/api/cliente.ts`, errores `{"detalle"}` → `ErrorApi`). Tipos de rutas y cuerpos generados con `openapi-typescript` desde `/openapi.json`; las respuestas de lectura no tienen `response_model` en FastAPI, así que sus tipos van a mano en `api/tipos.ts` (se anota en el PR). Estilos: variables de `tokens.css` + CSS Modules, sin Tailwind. Diálogos con `@base-ui/react`. El contrato de Fase 3 (`generar`, `trabajos/{id}`, `cancelar`) se implementa detrás de una interfaz `Trabajos` con una versión real y una simulada (`VITE_TRABAJOS_SIMULADOS=1`).

**Spec:** `docs/PLAN_WEB.md` §6 Fase 4, §7 (componentes y `checks/diseno.py`), §8 (pintado < 1 s).

## Global Constraints

- Interfaz y mensajes en español. No se toca `an/`, `tests/` del núcleo ni los docs de otras fases.
- Sin colores literales fuera de `web/src/tokens.css` (los colores de turnos desconocidos vienen como dato de la API y se aplican con estilo en línea).
- Sin Tailwind. Sin librerías de estado ni de datos (fetch + hooks).
- Foco visible en todo control; navegación completa con teclado; la grilla es una `table` con celdas enfocables (flechas).
- Cookie `an_sid` es `Secure`: en desarrollo se usa `http://localhost` (el navegador la acepta) y la API arranca con `AN_ORIGEN=http://localhost:5173`.
- Commits en español, imperativo, con `Co-Authored-By`. Rama: `claude/web-fase-4-8e2a7d`.
